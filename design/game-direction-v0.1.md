# حارس القافلة — Game Direction v0.1

## Core loop
تجهيز الحمولة → اختيار أدوات بوزن محدود → دفاع سريع باللمس → مكافأة → ترقية → جولة أصعب.

## Arabic identity
- البيئة: طرق وقوافل وصحراء وقلعة عربية خيالية.
- اللغة: عربية من الواجهة إلى المكافآت.
- العناصر: قوس، درع، مشعل، فأس، ماء، بوصلة، سيف، ذهب.
- الأسلوب: فخم/سينمائي خفيف، وليس كرتون أطفال.

## Prototype
- 3 موجات.
- سعة حمولة 10.
- اختيار معدات قبل الجولة.
- أعداء لمس سريع.
- عملات ومكافأة.
- تصميم عمودي للموبايل.

## Monetization hooks
Rewarded: إحياء القافلة أو مضاعفة مكافأة الجولة.
Interstitial: بعد نهاية جولة، وليس أثناء اللعب.
IAP لاحقاً: أشكال/مظاهر وأدوات تجميلية.

## Technical target
الـprototype الحالي للعب واختبار الميكانيكية في المتصفح فقط.
الإصدار النهائي لـTikTok Mini Games يجب أن يُبنى Native Runtime باستخدام Unity/Cocos/Laya، وليس HTML.
